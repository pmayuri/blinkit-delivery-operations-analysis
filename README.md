# Blinkit Delivery Operations & Performance Analysis

## 📌 Overview

Analyzed **100,000 delivery orders** using PostgreSQL and Excel to identify operational patterns related to delivery delays, refunds, customer ratings, product categories, and platforms.


## 🎯 Business Objectives

* Analyze delivery delay performance
* Identify high-delay product categories
* Compare refunds for delayed vs on-time orders
* Evaluate customer service ratings
* Analyze order volume by platform
* Generate actionable operational recommendations

## 📊 Dashboard

The Excel dashboard includes:

* Total Orders
* Delivery Delay Rate
* Refund Rate
* Average Service Rating
* Delay Rate by Category
* Refund Rate: Delayed vs On-Time
* Service Rating: Delayed vs On-Time
* Order Volume by Platform

## 🔍 Key Insights

Grocery has the highest delay rate: 13.82%.

Beverages has the lowest: 13.52%.

The difference is only 0.30 percentage points, suggesting that delays are not concentrated in one particular category.

Approximately 13,700–13,800 orders per 100,000 appear to be delayed based on these category rates.
